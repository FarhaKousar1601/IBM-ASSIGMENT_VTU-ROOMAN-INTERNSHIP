# IBM ASSIGMENT - VTU ROOMAN INTERNSHIP

This repository contains a collection of data science and machine learning projects completed as part of the IBM assignment and VTU Rooman internship. The projects focus on practical data analysis, predictive modeling, and performance evaluation using Python and Jupyter notebooks.

## Project Overview

The repository includes the following notebooks:

- Customer_Churn_Prediction.ipynb  
  A customer churn prediction model built using a sample customer dataset. It applies logistic regression to predict whether a customer is likely to churn based on age and tenure. The notebook includes data aggregation, model training, and evaluation.

- Predicting_House_Prices.ipynb  
  A house price prediction project using the California Housing dataset. It compares multiple regression models, including Linear Regression, Decision Tree Regressor, and Random Forest Regressor. The Random Forest model produced the best performance among the tested models.

- Analysis_using_clustering_algorithm.ipynb  
  A notebook focused on clustering-based analysis for exploratory data insights and pattern discovery.
